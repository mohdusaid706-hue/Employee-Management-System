## 📝 Project Description

**Employee Management System** is a web application developed using **Spring Boot** for the backend and **React JS** for the frontend. The system integrates with **HeidiSQL** for database management, allowing CRUD operations for employee data.

### Key Features:
- User management with salary and attendance tracking
- Admin control to manage employee details, mark attendance, assign rates, and calculate salaries
- Seamless data communication using Axios between the frontend and backend

## 💾 Installation Instructions

Follow these detailed steps to set up the **Employee Management System**:

### **1. Clone the Repository**

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd employee-management-system
## **2.Backend Setup**
# Navigate to the backend directory
cd backend

# Run the backend server using Maven
./mvnw spring-boot:run
The backend will run on: http://localhost:8080.
## **3.Frontend setup**
# Navigate to the React frontend directory
cd frontend

# Install the dependencies
npm install

# Start the React development server
npm start
The frontend will run on: http://localhost:3000.
